# Quickshook

Desktop accounting that stays on your computer: invoices, bills, banking, payroll, inventory and more than 60 reports, in one company file you own. No cloud account, and no internet needed.

- **Website:** https://mitch011.github.io/quickshook-releases/
- **Download for Windows 10/11 (64-bit):** [Quickshook-Setup.exe](https://github.com/mitch011/quickshook-releases/releases/latest/download/Quickshook-Setup.exe)
- **User guide (PDF):** [Quickshook-User-Guide.pdf](https://github.com/mitch011/quickshook-releases/releases/latest/download/Quickshook-User-Guide.pdf)

This repository holds the website and the released installers.
