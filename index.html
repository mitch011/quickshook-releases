Questions

Does Quickshook need the internet?

No. It runs entirely on your computer and never connects to the internet. Downloading the installer is the only time you need a connection.

Where is my data kept?

In a company file (ending in .qsk) wherever you save it: your Documents folder, a shared drive or a USB stick. Back it up like any other important file, or let Quickshook make automatic backups.

Can I bring my data from QuickBooks Desktop?

Yes. Export your lists and transactions from QuickBooks Desktop as an IIF file and import it with File → Import → IIF Files. Quickshook checks every transaction against the file so your balances match. You can also export back to IIF.

Can my accountant work on my books?

Yes. Send them an Accountant’s Copy: they make their adjustments and send back a changes file you import, while you keep working on everything after the dividing date.

Does it do payroll?

Yes. It calculates paychecks with 2026 US federal withholding and payroll taxes, the state rules you set up, and full Puerto Rico payroll.

Is there a Mac version?

Not yet. Quickshook runs on Windows 10 and 11 for now.
